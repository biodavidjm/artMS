# MSstats modelQC example

Normalized data obtained from the
[`artmsQuantification()`](http://artms.org/reference/artmsQuantification.md)
step of the PH dataset (global analysis)

## Usage

``` r
artms_data_ph_msstats_modelqc
```

## Format

A data frame resulting from running the latest version of
[`MSstats::groupComparison`](https://rdrr.io/pkg/MSstats/man/groupComparison.html)
function required as input for artmsAnalysisQuantifications()
