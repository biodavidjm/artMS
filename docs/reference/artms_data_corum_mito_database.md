# CORUM Protein Complexes database use for complex enrichment analysis

The list of protein complexes has been enriched with mitochondria
proteins from mouse, as described in this paper:

2018 - Ruchi Masand, Esther Paulo, Dongmei Wu , Yangmeng Wang, Danielle
L. Swaney, David Jimenez-Morales, Nevan J. Krogan, and Biao Wang
Proteome Imbalance of Mitochondrial Electron Transport Chain in Brown
Adipocytes Leads to Metabolic Benefits. Cell Metab. 2018 Mar 06;
27(3):616-629.e4

## Usage

``` r
artms_data_corum_mito_database
```

## Format

Tab delimited file.
